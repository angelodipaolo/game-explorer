# Platform icon assets

The per-system icons in this directory (one SVG per platform slug) are
vendored, unmodified, from the RetroArch XMB "monochrome" icon theme:

- Source: https://github.com/libretro/retroarch-assets
  (`src/xmb/monochrome/`, commit 73106363e14e34c08a5854b4cfbc29f184e3b783)
- License: Creative Commons Attribution 4.0 (CC-BY-4.0)
  https://creativecommons.org/licenses/by/4.0/
- Attribution: libretro / RetroArch contributors

Slug-to-source mapping is by system name (e.g. `nes.svg` is
"Nintendo - Nintendo Entertainment System.svg", `pc.svg` is
"IBM - PC and Compatibles.svg", `tg16.svg` is
"NEC - PC Engine - TurboGrafx 16.svg"). `switch2.svg` is a copy of the
Switch icon; the UI overlays a "2" badge.

Exceptions:

- `ps5.svg` is from Controllercons v2.1 by Kieran McClung,
  https://controllercons.github.io/, licensed under the SIL Open Font
  License 1.1 (https://openfontlicense.org/). Per the OFL, this file
  remains under that license.
- `generic.svg` is adapted from the Kenney Input Prompts pack
  (https://kenney.nl/assets/input-prompts), CC0 1.0 Universal.

The console and controller shapes may evoke trademarks of their respective
manufacturers (Nintendo, Sony, Microsoft, Sega, etc.); they are used here
nominatively, to identify which system a game runs on.
